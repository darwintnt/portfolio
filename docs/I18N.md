# Internacionalización (i18n) - Documentación

## 📁 Estructura de Carpetas

```
src/
├── i18n/
│   ├── index.ts              # Configuración principal de i18n
│   └── locales/
│       ├── es.json           # Traducciones en español
│       └── en.json           # Traducciones en inglés
├── composables/
│   └── useLanguage.ts        # Composable para manejar idioma
└── components/
    ├── LanguageSwitcher.vue          # Toggle simple de idioma
    └── LanguageSwitcherDropdown.vue  # Dropdown selector de idioma
```

## 🚀 Características Implementadas

- ✅ Detección automática del idioma del navegador
- ✅ Persistencia en localStorage
- ✅ Cambio de idioma en tiempo real
- ✅ SEO-friendly (actualiza atributo `lang` del HTML)
- ✅ TypeScript con tipado fuerte
- ✅ Dos componentes de UI (toggle y dropdown)
- ✅ Composable reutilizable

## 📖 Uso Básico

### 1. En Templates (usando Composition API)

```vue
<template>
  <div>
    <h1>{{ t('hero.title') }}</h1>
    <p>{{ t('hero.description') }}</p>
  </div>
</template>

<script setup>
import { useI18n } from 'vue-i18n';

const { t } = useI18n();
</script>
```

### 2. En Templates (usando Options API)

```vue
<template>
  <div>
    <h1>{{ $t('hero.title') }}</h1>
    <p>{{ $t('hero.description') }}</p>
  </div>
</template>

<script>
export default {
  name: 'MyComponent',
};
</script>
```

### 3. Usando el Composable useLanguage

```vue
<script setup>
import { useLanguage } from '@/composables/useLanguage';

const {
  currentLocale, // Idioma actual ('es' | 'en')
  availableLocales, // Lista de idiomas disponibles
  currentLanguage, // Info del idioma actual
  changeLocale, // Función para cambiar idioma
  toggleLocale, // Función para alternar idioma
  isCurrentLocale, // Verificar si es el idioma actual
  t, // Función de traducción
} = useLanguage();

// Cambiar idioma
const switchToEnglish = () => {
  changeLocale('en');
};

// Alternar entre idiomas
const toggle = () => {
  toggleLocale();
};
</script>
```

### 4. Traducciones con Variables

**JSON:**

```json
{
  "welcome": "Bienvenido, {name}!",
  "items": "Tienes {count} items"
}
```

**Template:**

```vue
<template>
  <p>{{ t('welcome', { name: 'Darwin' }) }}</p>
  <p>{{ t('items', { count: 5 }) }}</p>
</template>
```

### 5. Traducciones Plurales

**JSON:**

```json
{
  "projects": "sin proyectos | 1 proyecto | {count} proyectos"
}
```

**Template:**

```vue
<template>
  <p>{{ t('projects', 0) }}</p>
  <!-- sin proyectos -->
  <p>{{ t('projects', 1) }}</p>
  <!-- 1 proyecto -->
  <p>{{ t('projects', 5) }}</p>
  <!-- 5 proyectos -->
</template>
```

### 6. Traducciones Anidadas

**JSON:**

```json
{
  "user": {
    "profile": {
      "name": "Nombre",
      "email": "Correo"
    }
  }
}
```

**Template:**

```vue
<template>
  <p>{{ t('user.profile.name') }}</p>
  <p>{{ t('user.profile.email') }}</p>
</template>
```

## 🔧 Configuración Avanzada

### Agregar un Nuevo Idioma

1. **Crear archivo de traducción:** `src/i18n/locales/fr.json`

2. **Actualizar src/i18n/index.ts:**

```typescript
import fr from './locales/fr.json';

export type Locale = 'es' | 'en' | 'fr';
export const SUPPORTED_LOCALES: Locale[] = ['es', 'en', 'fr'];

const messages = {
  es,
  en,
  fr,
};
```

3. **Actualizar src/composables/useLanguage.ts:**

```typescript
const availableLocales = computed(() => [
  { code: 'es', name: 'Español', nativeName: 'Español' },
  { code: 'en', name: 'English', nativeName: 'English' },
  { code: 'fr', name: 'Français', nativeName: 'Français' },
]);
```

### Cambiar Idioma por Defecto

Edita `src/i18n/index.ts`:

```typescript
export const DEFAULT_LOCALE: Locale = 'en'; // Cambiar a 'en'
export const FALLBACK_LOCALE: Locale = 'en';
```

## 🌐 SEO y Accesibilidad

El sistema actualiza automáticamente:

- Atributo `lang` del documento HTML
- localStorage para persistencia
- Permite navegadores indexar mejor el contenido

## 📝 Buenas Prácticas

1. **Estructura de claves descriptivas:**

   ```json
   {
     "components.button.submit": "Enviar",
     "pages.home.title": "Inicio"
   }
   ```

2. **Mantener sincronizados los archivos JSON:**
   - Todas las claves deben existir en todos los idiomas
   - Usa las mismas claves en `es.json` y `en.json`

3. **Usar valores por defecto:**

   ```vue
   {{ t('key.that.might.not.exist', 'Valor por defecto') }}
   ```

4. **Variables en minúsculas:**

   ```json
   {
     "greeting": "Hola, {username}"
   }
   ```

5. **Extraer textos largos:**
   - No dejar textos hardcodeados
   - Todo lo visible debe estar en archivos de traducción

## 🧪 Ejemplo Completo

```vue
<template>
  <div class="my-component">
    <!-- Traducción simple -->
    <h1>{{ t('hero.title') }}</h1>

    <!-- Traducción con variable -->
    <p>{{ t('welcome', { name: userName }) }}</p>

    <!-- Traducción plural -->
    <p>{{ t('projects', projectCount) }}</p>

    <!-- Selector de idioma -->
    <LanguageSwitcher />

    <!-- Usar idioma actual -->
    <span>{{ currentLanguage?.nativeName }}</span>

    <!-- Botón personalizado -->
    <button @click="changeLocale('en')">Switch to English</button>
  </div>
</template>

<script setup>
import { ref } from 'vue';
import { useLanguage } from '@/composables/useLanguage';
import LanguageSwitcher from '@/components/LanguageSwitcher.vue';

const { t, currentLanguage, changeLocale } = useLanguage();
const userName = ref('Darwin');
const projectCount = ref(12);
</script>
```

## 🚀 Escalabilidad Futura

Para proyectos más grandes, considera:

1. **Lazy loading de traducciones:**
   - Cargar solo el idioma activo
   - Reducir bundle inicial

2. **Namespaces:**
   - Separar traducciones por módulos
   - `home.json`, `about.json`, `contact.json`

3. **Validación de traducciones:**
   - Scripts para verificar claves faltantes
   - Tests automatizados

4. **CMS para traducciones:**
   - Usar herramientas como Tolgee, Lokalise
   - Permitir a no-desarrolladores gestionar traducciones
